# Тесты

Покрыта логика, которая не требует внешних сервисов:

- `test_validators.py` — нормализация телефона, разбор контакта, парсинг опыта
  в свободной форме («полтора года», «1 год 6 месяцев», «нет опыта»).
- `test_ai_scoring.py` — извлечение JSON из ответа модели (включая обёртки
  прозой и markdown-блоки) и поведение при отказе AI-провайдера.

Запуск:

```bash
pip install pytest pytest-asyncio aiohttp
pytest -q
```
